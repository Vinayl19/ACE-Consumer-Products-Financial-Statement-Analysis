# ACE Consumer Products Ltd. – Financial Statement Analysis

## Project Overview

This project presents a three-year financial statement analysis of ACE Consumer Products Ltd. using Microsoft Excel.

The analysis covers FY2023 to FY2025 and focuses on profitability, liquidity, leverage, and overall financial performance.

## Financial Statements

- Income Statement
- Balance Sheet
- Cash Flow Statement

## Analysis Performed

- Gross Profit Margin
- Operating Profit Margin
- Net Profit Margin
- Return on Assets (ROA)
- Return on Equity (ROE)
- Current Ratio
- Quick Ratio
- Debt-to-Equity Ratio
- Debt-to-Assets Ratio
- Interest Coverage Ratio
- Three-year financial trends
- Key financial insights

## Key Findings

- Revenue increased from ₹500 Cr in FY2023 to ₹680 Cr in FY2025.
- Net profit increased from ₹49 Cr to ₹82 Cr.
- Net profit margin improved from 9.80% to 12.06%.
- Current ratio improved from 1.67x to 1.80x.
- Debt-to-equity ratio declined from 1.02x to 0.84x.
